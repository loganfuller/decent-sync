Glossary

Decent Sync keeps the coffee data of several Decent espresso machines, across one or more physical sites, in one place. It shares a library of beans, bean batches, profiles, equipment and recipes between those machines and collects every shot they pull.

Hardware and places

Machine: A piece of Decent espresso hardware: any DE1 model (DE1, DE1+, DE1Pro, DE1XL, DE1Cafe, DE1XXL, DE1XXXL) or a Bengle. Identity follows the hardware, so replacing its tablet does not make it a new machine. Avoid: Device, DE1 (when any model is meant), station

Unidentified Machine: A machine that has connected without reporting a real serial number, and that nobody has yet linked to a known machine.

Pending Machine: Hardware the server has seen but no machine entry covers: a tablet connected with another machine’s token while reporting different hardware (a mismatch), or a shot recorded on hardware the server doesn’t know. An Admin either creates a machine entry for it or dismisses it. Avoid: Unknown machine, orphan

Capture-only Machine: A machine whose records the server collects but that takes no part in the library: it has no location, or an Admin has turned sharing off for it. Avoid: Read-only machine, unsynced machine

Token: The secret a machine’s plugin connects with. It belongs to one machine and is bound to the hardware that machine first reports. Avoid: Key, password, API key

Tablet: The Android device running Decaid that is attached to a machine, together with its Decaid data: resetting that data makes a new tablet, and restoring a backup onto another device brings back the tablet it came from. A tablet can be swapped or moved to another machine without changing the machine’s identity. Its tablet id is a random id the plugin keeps in that data to tell tablets apart, such as two connecting with one machine’s token; it is not the machine’s identity. Avoid: Machine, client, install

Skin: The app baristas use on a tablet in place of Decaid’s own screens, such as Streamline. It reads and changes the machine’s workflow through Decaid’s API, as the plugin does, and through the plugin it reads what the server holds for its machine’s location: that location’s shots and its recipes’ reference shots. Avoid: Theme, front end

Machine Settings: What a machine’s firmware is set to apart from what its workflow sets, such as its fan threshold, heater settings and sensor calibration. Not DYE2’s “machine settings” of a recipe, which are its steam, hot water and flush settings. Avoid: Machine config, DE1 settings

Tablet Settings: Decaid’s own settings on a tablet, such as how it uses its scale and charges, and when it puts the machine to sleep and wakes it. They go with the tablet when it moves to another machine. Avoid: App settings, preferences, config

Settings Edit: A change to a machine’s or tablet’s settings made through the server, as in the management interface, kept with who made it and when, and what came of it. Avoid: Settings change, command

Settings History: A machine’s record of what its tablet reported for its Machine Settings, Tablet Settings, scale, paired devices, sensors, plugins and Skins: each value from when the server received it, whatever changed it, and for a change made through a Settings Edit or a Software Action, that edit or action. A change made on the tablet, by another app or by the machine itself is kept too, but tied to no person. Avoid: Settings log, audit log, Settings changes (a Settings Edit is one change made through the server)

Plugin: An add-on Decaid runs on a tablet, such as DYE2. “The plugin” on its own is Decent Sync’s, which connects its tablet to the server. Avoid: Extension, add-on

Tablet Software: Decaid, its plugins and its Skins as installed on a tablet, each with its version and how it updates. Avoid: Installed software, extensions, firmware (which is the machine’s)

Software Action: Something done to a tablet’s software through the server, such as installing a plugin, changing a plugin’s settings, changing how a plugin or Skin updates or reloading the Skin, kept with who asked for it and when, and what came of it. Avoid: Command, Settings Edit (which changes a Machine Setting or a Tablet Setting)

Pinned: Of a plugin or Skin: installed from one fixed build, so no update check moves it. One that is not pinned follows releases, follows a branch, or is not updated. An Admin changes which with a Software Action, which installs the item again from the source chosen. Avoid: Held, locked, frozen

Machine State: What a machine is doing at a moment, such as pulling a shot, steaming, purging after steaming, flushing, pouring hot water, idling or sleeping. Purging is the steam wand’s purge after steaming, not a flush of the group head or draining the machine for transport. Avoid: Status (a machine’s status is whether it is online), mode, purge (for a flush)

Live View: The management interface’s real-time picture of what one machine is doing and measuring, shown while someone has its page open. Nothing in it is kept. Avoid: Live mode, dashboard, monitor

Machine Activity: What happened on a machine over a period and how much it was used: its workflow changes, loaded recipes and machine states, with how many shots, steam records, flushes and hot water pours it made and how long it spent in each machine state. Avoid: Machine history, machine log, usage report

Connection Id: The id Decaid uses to reach a machine: a Bluetooth address or a USB id. The server remembers a machine’s connection ids as aliases, but they are not its identity. Avoid: Machine id, MAC (when a USB id is possible)

Location: A physical site where machines are used, such as a roastery lab or a cafe, with its own time zone. A machine can be unassigned; once assigned, it is at one location at a time. The machines at one location work like the groups of a single commercial espresso machine: they share equipment and recipes. Avoid: Site, store, shop, venue

Location History: The record of which location a machine was at from which time. It decides the location each shot and steam record is credited to, and correcting it re-credits them.

Overview: The management interface’s picture of each location over a day or a few: whether its machines are up, which recipes it is pulling, and how their shots are landing on each machine. Avoid: Dashboard, home, report

Equipment: Gear used alongside a machine that can be shared between machines without changing what the machine is: grinders, baskets and tools. A grinder belongs to one location; baskets and tools are in the library, and each location shows or hides them. Avoid: Gear, accessories. A tablet is not equipment.

Grinder: One physical grinder, with its own burrs and calibration, that grinds coffee at a numbered or named setting. It may declare the range of its setting and of its RPM, and a default for each, which a machine takes as a barista picks the grinder on it.

Basket: A model of filter basket, such as a 20 g high-flow basket. One basket stands for every copy of that model, at every location.

Tool: A kind of equipment other than a grinder or basket that a recipe or shot can name, such as a tamper, WDT tool, puck screen, portafilter or dripper. Avoid: Accessory, gear

Scale: A weighing device paired with a machine’s tablet that weighs the shot as it is pulled.

Auxiliary Scale: A second scale used for something other than weighing the shot, such as weighing ground coffee into a portafilter. Avoid: Dosing scale, second scale

People

Admin: A person who can change everything on the server, including machines, tokens and hard deletes.

Barista: The person who pulled a shot, as named on the tablet. A barista doesn’t need an account. Names that differ only in case or the spaces around them are one barista.

Staff: A person who works at one or more locations. They can edit the library’s shared content anywhere, and move machines, edit machines’ settings, change what their locations offer, manage recipes and record stock there. Avoid: User (when the role matters), barista (a barista may not have an account)

Viewer: A person who sees everything Staff see but Drafts, and changes nothing. Avoid: Read-only user, guest, observer

Connected App: An assistant app, such as Claude or ChatGPT, that a person has allowed to read, or to read and change, the server’s data as them, within what their own account may do. Each approval makes one, so Claude Code on two laptops is two Connected Apps. It lasts until the person or an Admin disconnects it. Avoid: Token (a Machine’s), API key, integration, client, connection

Coffee

Bean: A coffee as sold by a roaster, identified by roaster and name. It is offered at each location where one of its batches is, and, until one of its batches is added there, where a tablet there created, linked or un-archived it. Avoid: Coffee (when the product is meant), blend

Bean Batch: One roast of a bean that baristas pick: a single roaster run if you roast, or one roast date from your supplier if you buy. A batch is at a location from when it’s added there until it’s finished there, and can be at several locations at once. Avoid: Roast (as a record), run, bag, bucket, lot

Stock: How much of a bean batch is held at one location, when it is tracked. Avoid: Inventory (for one batch at one place), remaining weight

Stock Movement: One recorded change to a batch’s stock at a location: a delivery, a transfer between locations, a count, or the coffee used by a shot. A location’s stock is the sum of its movements since the last count. Avoid: Adjustment, transaction

Profile: A program the machine follows while pulling a shot, such as a pressure or flow curve. Each location shows or hides each profile. Avoid: Recipe (a recipe is more than a profile)

Profile Version: One profile in a chain in which each was saved from the one before, shown as the versions of one profile. A change to a profile’s steps makes a new version; a change to its title, author or notes does not. Avoid: Revision; version (for one accepted edit in an item’s history)

Draft: A profile being written or changed in the management interface, held by the server and offered on no tablet. Publishing it makes it a profile, or a new profile version, or, where it changes only the title, author or notes of the profile it changes, edits that profile; it is gone once published or discarded. A machine at a location marked for it can follow a draft, taking its steps as they are saved, to try it. Avoid: Unsaved profile, working copy

Trial Shot: A shot pulled with a draft’s steps on a machine following it, kept with the steps it ran so it can be compared with what the draft was simulated to do. Avoid: Test shot, draft shot

Recipe: A named, saved dial-in for a coffee, such as the day’s recipe for one roast: its bean batch, profile, dose, yield, grinder and grind setting, basket and tools, and any steam, hot water and flush settings it holds. It is the whole shot: a machine that loads it is left with none of what the recipe names none of, such as a bean batch, grinder, grind setting, basket, dose or yield. Only for the steam, hot water and flush settings it holds none of does the machine keep its own. Its steam temperature may be “Off”, which turns steam off on a machine that loads it, as one it holds turns steam on. It belongs to one location, where any machine can load it, and baristas keep it current as they adjust the dial through the day. Avoid: Stored workflow, preset, favourite

Recipe Slot: One of a location’s nine numbered positions for a recipe, 1 to 9, shared by every machine at that location, like a programmed button on one group of a commercial machine. Streamline’s DYE strip has a button for each of slots 1 to 5 only; a recipe in one of 6 to 9 is a button on a Skin that shows nine, and DYE2 lists it. A recipe is in at most one slot, and keeps its identity when moved to another. One in slots 1 to 5 is on Streamline’s strip exactly while it is in its slot, so taking it off any machine’s strip takes it out of its slot at the location. One in no slot is kept at its location, where any machine can still load it, until someone puts it in one or archives it. Avoid: Recipe number, index

Loaded Recipe: The recipe a barista last applied on a machine, while they are still dialling it in, until they apply another recipe or a favourite, or change the profile. It belongs to the machine, as its workflow does: a change made on that machine is saved into the recipe, a bean batch of another bean picked there included, and a change to the recipe reaches that machine’s workflow at once. Avoid: Active recipe, current recipe

Workflow: What a machine is set up to do next: its current profile, dose, yield, bean batch, grinder and setting, and basket, plus its steam, hot water and flush settings, which loading a recipe sets, steam turned on or off as the recipe holds it, so machines at one location with different recipes loaded steam differently. Turning steam off at the machine never changes a recipe, and turning it back on takes the loaded recipe’s steam temperature. Avoid: Recipe (a recipe is saved; a workflow is current); rinse settings (Decaid’s name for the flush settings)

Shot: One extraction recorded on a machine: its measurements over time, what was used, and how it turned out. Avoid: Pull, brew, extraction (as a noun for the record)

Preheat: The part of a Shot’s recording before its profile starts, while the Machine heats its water. Preheat is shown with the Shot but isn’t counted in its duration or peaks. Avoid: Warmup, heater test

Reference Shot: The one shot chosen for a recipe to show how its shots should go, as a roaster chooses a reference roast for a roast profile: the recipe’s other shots are compared with it. A recipe has at most one, and it can be any shot, pulled on any machine at any location, with the recipe’s profile or another. It stays until someone chooses another or clears it, so changing the recipe’s grind, yield, bean batch or profile leaves it in place. A copy of a recipe starts with the same one. Avoid: Golden shot, best shot, baseline, target shot (a shot’s targets are its profile’s)

Time to first drip: How long after a shot’s profile starts its coffee first reaches the cup, as its scale shows it. A shot with no scale has none, and neither does one in which nothing poured.

Unfinished Shot: A shot in which nothing poured, as its machine and scale show it: its machine never reached pouring and its scale never showed a gram in the cup, past a cup weighed before the shot’s tare, so it was stopped in its Preheat or early in its preinfusion. A shot that reached its yield while its profile was still in the steps it counts as preinfusion poured, though its machine never reported pouring. A shot summary counts unfinished shots apart and leaves them out of its numbers. Avoid: Aborted shot, failed shot, sink shot

Shot Summary: What a set of shots have in common, by group: how many there are; for each number a shot has, such as its duration or its yield against its target, their median and the range the middle half of them fall in; and for what a shot either did or didn’t, such as stopping at its target, the share that did. Grouped by machine it compares machines, and grouped by day it shows a trend. Avoid: Statistics, report, dial-in health, analytics (for one result)

Out of spec: Of a machine’s shots of a recipe over a period, or of one shot: further than a margin from what they are measured against. Their duration is measured against the recipe’s reference shot’s, their yield against each shot’s own target, and their stopping against stopping at their target. A recipe is out of spec between machines where its fastest and slowest machines’ durations differ by more than the margin. Shots that are judged and not out of spec are within spec; too few shots are not judged. Avoid: Off, bad, failing, drifted, alert (an alert is Monitoring’s)

Stopped at target: A shot Decaid stopped as it reached its target: its target weight on the scale or, with no scale, its target volume. A shot stopped by hand, ended by its machine as its profile ran out, or cut short by an error did not. Avoid: Stopped on weight (a volume stop counts too)

Steam Record: One recorded use of a machine’s steam wand: its measurements over time and the milk temperature reached. Its recording also holds the steam starting up, the pauses after each stop, the puffs that keep the wand clear and the purge, which are shown with it but aren’t counted in its duration: that counts only the steaming. Avoid: Steam shot, steaming session

Library

Library: The beans, bean batches, profiles, equipment and recipes that the server keeps and shares with machines, some everywhere and some per location. Avoid: Collection, catalogue

Archived: A library item retired everywhere: kept so that past shots still name it, but offered nowhere. Avoid: Deleted, hidden (a profile is hidden at one location)

Lost Edit: An edit to a field of a library item that did not apply, because it lost to another edit of the same field made without seeing it, or because a record a barista entered on a tablet, of an item the library already had, held another value. It is kept in the item’s history. A tablet joining a location keeps none: the location’s values are written over its own. A tablet whose record held a value has seen it, so a value a barista changed on the tablet is never kept as a Lost Edit against their own change. Avoid: Conflict, clash, collision

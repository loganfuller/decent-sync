Decent Sync runs in production at its author's cafe.
[Releases](../../project/releases/) has what each release added. This page
has what is planned.

## Planned next

In no fixed order, and with no dates:

- **Monitoring**: noticing lost Shots, low water and dropped scale or Machine
  connections, with alerts.
- **Calibration**: checks of stop-at-weight, flow and temperature.
- **Bean Batches by Location**: scanning a batch's QR code in the cafe Skin.
  A batch's remaining weight at a Location already falls with each Shot
  pulled there, on its tablets too, and all or part of a batch is already
  moved between Locations.

## Following the work

- Each release in progress is a
  [milestone on GitHub](https://github.com/loganfuller/decent-sync/milestones),
  named by its version, with the issues it holds.
- To ask for something or report a problem,
  [open an issue](https://github.com/loganfuller/decent-sync/issues).
